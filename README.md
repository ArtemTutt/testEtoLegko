# Замер скорости скачивания

Небольшой консольный скрипт на Node.js. Он 10 раз последовательно скачивает данные по указанному URL, показывает результат каждого запроса, а в конце выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

- Node.js 22 или новее.
- Сторонние зависимости не требуются.

## Установка и запуск

Клонируйте репозиторий и перейдите в директорию проекта:

```bash
git clone <URL_репозитория>
cd <название_репозитория>
```

Запустите скрипт, передав HTTP(S)-адрес:

```bash
node speed-test.js 'https://speed.cloudflare.com/__down?bytes=1000000'
```

В примере используется Cloudflare, который отдаёт 1 000 000 байт на каждый запрос.

Можно указать другой HTTP(S)-адрес файла. Скрипт не сохраняет скачанные данные на диск.


## Как считается результат

- **Среднее время запроса** — время от начала `fetch()` до полного чтения тела ответа, усреднённое по 10 запросам. Измеряется в миллисекундах (`ms`).
- **Общий объём** — сумма байтов, прочитанных из тел всех 10 ответов. Выводится в байтах и мебибайтах (`MiB`, 1 MiB = 1 048 576 байт).
- **Скорость скачивания** — общий объём данных, разделённый на суммарное время выполнения 10 запросов. Измеряется в мебибайтах в секунду (`MiB/s`).

### Ограничения

Скрипт измеряет среднюю скорость получения данных с конкретного сервера, а не максимальную скорость интернет-соединения.

Измеряемое время включает установление соединения (когда оно необходимо), ожидание ответа и полное получение тела ответа.

Для сжатых HTTP-ответов подсчитанный объём данных может отличаться от фактического объёма байтов, переданных по сети.
